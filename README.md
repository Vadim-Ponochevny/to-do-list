# ToDo-Приложение на React

## О проекте

Простое и функциональное приложение для управления задачами (ToDo List), разработанное с использованием **React**. Приложение позволяет пользователю добавлять, просматривать, **редактировать** и **удалять** задачи. Все данные сохраняются в **Local Storage** браузера.

---

## Структура проекта

Ключевые папки (в src):

assets - хранятся все изображения в SVG формате
base - все стили CSS
components - все компоненты приложения + кастомные хуки

---

## Установка и запуск проекта

Для запуска проекта локально выполните следующие команды в терминале:

```bash
# Клонирование репозитория (замените URL)
git clone [URL_РЕПОЗИТОРИЯ]
cd имя-проекта

# Установка зависимостей
npm install

# Запуск проекта в режиме разработки
npm start
